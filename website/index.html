Sprawdź wiadomość

Reguły rozpoznają presję czasu, prośby o dane, kody BLIK, podejrzane płatności i instrukcje uruchamiania plików. Analiza nie odwiedza adresów.

Reputacja domen

Jawnie pobierana lista CERT Polska. Lokalna baza SQLite, data aktualizacji, atomowa wymiana i powrót do poprzedniej wersji. Dopasowania dokładnej domeny.

Sygnały Windows

Cache DNS jest próbkowany po włączeniu obserwacji. Opcjonalny monitoring TCP (domyślnie wyłączony) próbuje co 10 sekund wykrywać nowe połączenia i zapisuje wyłącznie metadane lokalnie; krótkie połączenia mogą zostać pominięte. Bez przechwytywania treści TLS, sterownika ani zmiany ustawień sieci.

Cache DNS nie pokazuje pełnych URL, procesów ani całego ruchu. DoH, VPN, połączenia po IP i krótkotrwałe wpisy mogą pozostać niewidoczne. WFP nie jest wdrożone. Narzędzie nie zastępuje Defendera.

Pytania, które warto zadać

Czy brak ostrzeżenia oznacza bezpieczeństwo?

Nie. Reguły i lista domen mają ograniczony zakres, a nowy atak może nie zostać rozpoznany.

Czy potrzebuję modelu AI?

Nie. Reguły i reputacja działają bez modelu. Nowy klient nie ma jeszcze podłączonego opcjonalnego providera AI.

Czy Chrome i Edge potrzebują rozszerzenia?

Do analizy pełnego adresu — tak. Rozszerzenie i host Native Messaging wymagają osobnej konfiguracji. Test w rzeczywistych przeglądarkach pozostaje wymagany. Obserwacja cache DNS działa niezależnie.

Czy działa bez internetu?

Reguły działają offline. Reputacja działa na ostatniej kopii przez 48 godzin, po czym jest oznaczana jako wygasła.
