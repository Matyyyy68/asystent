# PhreshPhish URL-only research evaluation

This isolated research tool measures the current Sentinel URL rules on PhreshPhish. It is not a product dependency and is not included in the Windows installer. The dataset is released under CC BY 4.0 for anti-phishing research; cite the [dataset paper](https://arxiv.org/abs/2507.10854) and retain attribution when sharing results.

All three network extractors verify the pinned dataset revision and the API license declaration (`cc-by-4.0`) before reading data. They refuse to start unless passed `--allow-network`; the PowerShell wrappers likewise require `-AllowNetwork` before creating temporary files or installing packages. Offline guard tests run with `npm test --prefix scripts/research/phreshphish`. The test extractor pins dataset revision `eca603e0ecd4f698f8d4d226c088659e72681239`, verifies the Parquet manifest, and reads only `sha256`, `url`, and `label` using HTTP range requests. It refuses full-file responses, limits any one range to 16 MiB, and never requests the HTML column or visits dataset URLs. The first test row was inspected during a one-row API feasibility check, so the test extractor skips it. It writes the selected columns to a unique temporary directory, passes them to Sentinel's local URL evaluator, and removes the directory in `finally`.

`train-and-evaluate.ps1 -PythonPath <python.exe> -AllowNetwork` is a separate research experiment. It reads the official `train` split, derives 70/15/15 train/calibration/registrable-domain holdout partitions using the repository's Public Suffix List, trains a hashed character n-gram logistic model, and measures the frozen product rules on the internal holdout. After the model and thresholds are fixed from train/calibration, it scores the pinned official `test` split once; the test labels never feed fitting, threshold selection, or model changes. It then scores the full test once for the source's official 975 low-base-rate subsets, using only record hashes from those subset files, and reports per-base-rate means with 95% benchmark-level percentile bootstrap intervals. One test record was previously inspected during API feasibility checking, before model development; it remains included in these descriptive benchmark measurements and was never used for fitting or threshold changes. Python and Node dependencies are pinned and installed only under a unique `%TEMP%` directory. Downloaded columns, subset lists, derived splits, package files, score CSV and intermediate reports are removed when the run completes. The final summary containing metrics, thresholds and checksums is saved to `docs/PHRESHPHISH-OFFICIAL-BENCHMARKS.json` by default; choose another path with `-ReportOutputPath`. The dataset's CC BY 4.0 card restricts use to anti-phishing research, so the screening model is never built into the product.

Run from the repository root:

```powershell
pwsh -NoProfile -File scripts/research/phreshphish/evaluate.ps1 -AllowNetwork
pwsh -NoProfile -File scripts/research/phreshphish/train-and-evaluate.ps1 -PythonPath C:\path\to\python.exe -AllowNetwork
```

The report includes the dataset revision, row counts, SHA-256 of extracted record IDs and temporary CSV, range-request count/bytes, confusion matrix, threshold, per-benchmark confidence intervals, rule version, and `URLsOpened=0`. The script rejects a changed dataset revision, partial Parquet conversion, changed test file sizes, invalid records, or a server that ignores range requests. The generated CSV is deleted after evaluation.
