# Archiwum migracji

Ten katalog nie jest wspieranym klientem i nie jest częścią Sentinel.sln ani nowego instalatora.
WPF zachowano tymczasowo jako źródło implementacji UI Automation, ustawień AI i starej migracji danych.
Nowym interfejsem jest desktop/ (React + Electron). Nie uruchamiaj starego i nowego klienta jednocześnie.
Usunięcie archiwum wymaga zakończenia przenoszenia wartościowych funkcji i walidacji migracji danych.
