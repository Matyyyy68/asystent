# PLAN-004 — wspólny model zdarzeń i detekcja

1. **Cel:** wersjonowane, testowalne zdarzenie wspólne dla ręcznych reguł, DNS, browsera, plików i przyszłego Enterprise.
2. **Stan obecny:** lokalny `SecurityEvent` i Enterprise DTO mają różne zakresy, ale wspólny transportowy kontrakt `EnterpriseEventV1` oraz batch/result w `src/Sentinel.Contracts` są współdzielone przez klienta i serwer. Wspólny walidator pilnuje ID, czasu, kategorii, ryzyka, kodu reguły, źródła i wersji schematu.
3. **Braki:** deduplikacja między odrębnymi modułami oraz kalibracja confidence. Jawne `eventId` deduplikuje ponowiony zapis lokalny od v0.15.31; zdarzenia bez identyfikatora nadal dostają nowy GUID. Wydanie v0.15.34 dodaje ograniczone korelowanie startu procesu z TCP/UDP (zgodny PID i nazwa, 60 s). Bieżąca zmiana dodaje w SQLite v16 wąskie scalanie wykryć CERT o tym samym skrócie dokładnego hosta oraz lokalnych dopasowań SHA-256 plików; wymagane są ten sam rodzaj sygnału, ryzyko, okno 60 s i nowe źródło; zachowuje osobne EventId, czas, źródło i dowody w tabeli obserwacji. Dla URL bez sygnału CERT ręczne i browser warnings scalają się tylko przy zgodnym hashu dokładnego hosta i identycznym zestawie kodów url.*; pozostałe zdarzenia pozostają osobne. Korelacja domenowa nie cofa już czasu grupy dla zdarzeń dostarczonych poza kolejnością; dużo starsze zdarzenia nie nadpisują aktualnej grupy. Adapter Enterprise mapuje kanoniczne kategorie analizy i znane źródła przez jawne reguły; niekanoniczny tekst wyświetlany nie jest przeszukiwany. Batch, w którym to samo ID powtarza się w ramach jednej transakcji, nadal jest odrzucany atomowo.
4. **Decyzje:** additive SQLite migration; tekst prywatny/pełny URL pozostaje wyłączony; confidence oddzielone od ryzyka; wartości nieznane nie są wymuszane.
5. **Zależności:** `LocalStore`, kontrakt server API v1 (kompatybilność), retencja/eksport, klient Electron.
6. **Etapy:** (a) wspólny kontrakt v1 i walidator — wykonano; (b) migracja i test legacy db — wykonano; (c) adapter starych zdarzeń — częściowo; (d) `ruleVersion/source/evidence codes` — źródło, wersja i walidowane kody dowodowe wykonane w kandydacie v0.15.35; (e) idempotencja/status false positive wykonane; korelacja process-to-network działa w v0.15.34; wydanie v0.15.37 dodaje czasowe grupowanie po domenie, a v0.15.38 utrwala URL evidence codes dla browser-extension, aby wyjaśnienie wspólnej grupy w UI poprawnie odróżniało korelację domeny od korelacji procesu. Historia grupuje powiązane wpisy w jeden rozwijany widok, a scalone wykrycia pokazują źródła i dowody każdej obserwacji; szeroka deduplikacja pozostaje; ograniczona korelacja dopasowań plikowych używa lokalnego SHA-256; ręczna analiza i rozszerzenie scalają też URL warningi z tym samym hashem hosta, zestawem kodów url.*, ryzykiem i oknem 60 s; (f) adapter Enterprise — wspólne DTO oraz jawne mapowanie kanonicznych kategorii i znanych źródeł wykonane; starych zdarzeń bez stabilnych identyfikatorów nie da się jednoznacznie sklasyfikować.
7. **Pliki:** `src/Sentinel.Contracts/EnterpriseEventV1.cs`, `Models.cs`, `LocalStore.cs`, `Sentinel.Engine/Program.cs`, serwerowe `SecurityEvents.cs`, testy Core/API, renderer.
8. **Prywatność:** bez treści, haseł, pełnych URL i ekranu; `evidence` ograniczone do kodów/przesłanek redagowanych; retention.
9. **Testy:** migracja starych baz, brak utraty historii, enum/version validation, idempotence, retencja, eksport redaction, cross-contract fixtures. `DetectionScenarioEvaluationTests` używa 32 jawnie syntetycznych przypadków: TP=15, FP=0, TN=17, FN=0; osobne testy regresyjne sprawdzają brandowe TLD, exact-brand low signal i zachowanie alertu dla `googll.store`. `AnalysisTests` obejmują też mieszane etykiety łacińsko-greckie/cyrylickie i kontrolne IDN. `scripts/evaluate-phiusiil.ps1` raportuje URL-only metryki zbioru oraz deterministyczny podział po domenie; `scripts/test-evaluate-phiusiil-split.ps1` sprawdza powtarzalność, spójne grupowanie subdomen, kompletność macierzy i niepoprawne wiersze. UCI PhiUSIIL v2026.10.6: TP=4 363, FP=5, TN=134 845, FN=96 582, recall 4,3222%. Ponowiony pomiar nie zmienił metryk; pełny zbiór był wcześniej eksplorowany, więc split i metryki pozostają diagnostyczne, nie niezależne. Tranco top100k stanowi tylko sanity-check nazw domen, nie ground truth. Zewnętrzny, czasowo niezależny holdout i kalibracja nadal wymagają dalszej pracy. Ograniczenia i checksums są w `docs/DETECTION-EVALUATION.md`.
10. **Akceptacja:** wszystkie nowe źródła zapisują v1 zdarzenia; legacy odczyt działa; false positive i source są widoczne; feed/API nie przyjmują nadmiarowych pól.
11. **Ryzyka:** migracje i zgodność z istniejącymi danymi; schemat API wymaga wersjonowania.
12. **Status:** `IN_PROGRESS` — wspólny kontrakt Enterprise, walidacja, migracje SQLite, eksport/restore, evidence codes, jawne mapowanie kategorii do Enterprise i odporna na spóźnione zdarzenia korelacja domenowa są wdrożone. Historia grupuje zdarzenia o wspólnym correlationId w jeden rozwijany widok, zachowując każde źródło i dowody. v0.15.34 koreluje czasowo start procesu i TCP/UDP o zgodnym PID/nazwie; v0.15.37 grupuje czasowo DNS, rozszerzenie i ręczny URL przez hash domeny; v0.15.38 zachowuje kody przesłanek przeglądarki, by UI objaśniało źródło grupy. SQLite v16 scala potwierdzone wykrycia CERT między DNS, browserem i ręcznym URL oraz zgodne dopasowania lokalnego hash pliku z Downloads i ręcznej analizy. `2026.10.2` podniosła wagę `url.userinfo`; `2026.10.3` dodaje `url.auth_structure`, a `2026.10.4` dodaje `url.structure_combination`; `2026.10.5` osłabia exact-brand bez weryfikacji i rozpoznaje brandowe TLD; `2026.10.6` dodaje słaby sygnał mieszania łaciny z greką/cyrylicą w jednej etykiecie IDN, bez samodzielnego alarmu. Testy syntetyczne: TP=15, FP=0, TN=17, FN=0. UCI PhiUSIIL offline v2026.10.6 (ponowny pomiar, metryki bez zmian): TP=4 363, FP=5, TN=134 845, FN=96 582; recall 4,3222% pozostaje niski, a pełen zestaw służył do eksploracji i pomiaru bez holdoutu. Nie wnioskujemy o skuteczności produkcyjnej ani kalibracji confidence. Szersza deduplikacja innych źródeł oraz kalibracja nadal brakuje; confidence pozostaje puste.
