# PLAN-014 — ochrona URL w rozszerzeniu przeglądarki

1. **Cel:** ostrzegać użytkownika przed URL-em, który bieżące reguły Sentinel rozpoznają jako podejrzany, przy jawnej kontroli integracji i bez przesyłania historii przeglądania.
2. **Stan obecny:** Manifest V3 obsługuje Chrome i Edge przez Native Messaging host. Host produkcyjny korzysta z `UrlRequestProcessor`; analizuje nawigacje głównej karty przed nawigacją i zmiany historii SPA (`onHistoryStateUpdated`), a zgodę `integrationEnabled` odczytuje przed wysłaniem adresu. Zmiana historii identyczna z właśnie analizowanym URL-em jest deduplikowana; ramki podrzędne są pomijane. Testy jednostkowe sprawdzają te ścieżki, fail-closed, odczyt ustawienia, stan ostrzeżenia po restarcie service workera i obsługę odpowiedzi. Chrome 155 E2E na `*.test` sprawdził `status`, `analyze`, produkcyjne reguły `url.brand`, ekran ostrzeżenia oraz redakcję URL-a i hosta; użyto tymczasowego profilu i rejestracji mock hosta, po czym je usunięto.
3. **Braki:** nie zweryfikowano jeszcze pełnej instalacji/aktualizacji/deinstalacji rozszerzenia w świeżym profilu Chrome i Edge ani zachowania przy rzeczywistym błędzie lub braku hosta. Nie ma E2E dla przekierowań, iframe, pobierania, lifecycle wielu kart ani potwierdzenia zdarzenia SPA w przeglądarce; krótkie nawigacje i zmiany fragmentu mogą zostać pominięte. Brak jest polityki wydawania i aktualizacji rozszerzenia podpisanej przez zaufanego wydawcę.
4. **Decyzje architektoniczne:** przechowuj zgodę w `chrome.storage.local` i nie kontaktuj się z hostem przed jej odczytem. Ogranicz uprawnienia manifestu do wymaganych hostów i funkcji. Rozszerzenie tylko przedstawia wynik lokalnego hosta; nie wysyła URL-i do zewnętrznego reputacyjnego API i nie blokuje nawigacji bez jawnej decyzji użytkownika.
5. **Zależności:** Manifest V3, `chrome.storage`, Native Messaging, `Sentinel.UrlHost`, `UrlRequestProcessor`, istniejące UI ostrzeżenia oraz Chrome/Edge.
6. **Etapy:** (a) testy jednostkowe i statyczne uprawnień — wdrożone; (b) fail-closed zgody i obsługa restartu service workera — wdrożone; (c) Chrome E2E z fixture `.test` i produkcyjnym procesorem — wdrożone; (d) obsługa SPA przez `onHistoryStateUpdated` wraz z deduplikacją i testem głównej ramki — wdrożone; (e) pełny test instalacji hosta oraz rozszerzenia na świeżych profilach Chrome i Edge — otwarty; (f) przekierowania, iframe, pobieranie, lifecycle kart i E2E SPA — otwarte; (g) aktualizacja i deinstalacja w czystych profilach oraz kontrola braku pozostałości — otwarte.
7. **Pliki:** `browser-extension/manifest.json`, `browser-extension/service-worker.js`, `browser-extension/content-script.js`, `browser-extension/warning.html`, `browser-extension/warning.js`, `tests/Sentinel.NativeMessagingEngineHost`, `scripts/test-chrome-extension-e2e.cjs`, `installer/Sentinel.Setup/Program.cs`.
8. **Prywatność:** integracja jest opt-in; URL trafia wyłącznie do lokalnego Native Messaging hosta. Błędy i UI nie ujawniają surowego URL-a ani hosta w historii diagnostycznej. E2E używa wyłącznie domeny `.test`, blokuje zewnętrzne DNS i sprząta profil oraz rejestrację hosta.
9. **Testy:** rozszerzenie Node test/lint 17/17, w tym SPA analizowane raz wyłącznie w głównej ramce; walidator manifestu, host .NET bez ostrzeżeń, test `UrlRequestProcessor`, Chrome E2E dla `status`/`analyze` i ostrzeżenia, kontrola redakcji oraz inspekcja pozostałości profilu i HKCU. Dodać E2E dla SPA i Edge oraz testy lifecycle przed uznaniem pełnej integracji.
10. **Kryteria akceptacji:** zgoda wyłączona lub niedostępna nigdy nie wysyła URL-a; alert pokazuje wyłącznie zredagowane szczegóły; niepoprawny/brakujący host nie blokuje przeglądarki; Chrome i Edge przechodzą instalację, update i uninstall na czystych profilach bez pozostałości; wszystkie hosty i pliki manifestu mają weryfikowalny hash.
11. **Ryzyka i ograniczenia:** URL może zawierać dane wrażliwe, dlatego nie należy go logować ani przesyłać zewnętrznie. Silnik lokalny nadal ma krytyczne ograniczenia detekcji F03. Harmonogram zdarzeń Chrome może pominąć bardzo krótką nawigację; ten plan nie stanowi gwarancji blokowania każdej strony phishingowej.
