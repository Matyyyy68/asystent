# PLAN-003 — pliki i reputacja

1. **Cel:** na jawne żądanie oceniać wybrany plik przez hash, podpis i audytowane źródło reputacji.
2. **Stan obecny:** `Sentinel.Engine` na jawne żądanie otwiera wybrany plik do 256 MiB tylko do odczytu, liczy SHA-256, zwraca status Authenticode i sprawdza dokładne dopasowanie do lokalnej listy hashy zaimportowanej przez użytkownika. Opcjonalny lookup MalwareBazaar wysyła wyłącznie SHA-256 po osobnym kliknięciu; osobisty Auth-Key jest chroniony DPAPI. Brak dopasowania w którymkolwiek źródle nie jest werdyktem bezpieczeństwa.
3. **Braki:** walidacja/ocena zaufania podpisu, niezależne źródło i świeżość lokalnego feedu, test z autoryzowanym kluczem przeciw prawdziwemu API, pobrane pliki i monitorowanie lokalizacji.
4. **Decyzje:** ręczny skan i jawne lookup; brak automatycznego odczytu prywatnych katalogów; brak uploadu/próbkowania plików. MalwareBazaar community API wymaga Auth-Key i jest domyślnie nieaktywne; przed użyciem należy zapoznać się z [warunkami dostawcy](https://bazaar.abuse.ch/api/), ponieważ zastosowanie komercyjne może wymagać płatnego API. Lokalny feed pozostaje dostępny offline.
5. **Zależności:** podpis Authenticode/WinVerifyTrust, osobisty Auth-Key i zgodność z warunkami źródła, model zdarzeń.
6. **Etapy:** (a) ograniczenie rozmiaru, uchwyt tylko do odczytu i TOCTOU — wdrożone; (b) sprawdzenie Authenticode przez izolowany Windows PowerShell bez ładowania profili — wdrożone; (c) lokalny provider dokładnych SHA-256 z limitem 20 MiB/250 000 wpisów i atomową walidacją — wdrożony; (d) ręczny wybór pliku do skanu i listy — wdrożone; (e) ręczny hash-only lookup MalwareBazaar, stały HTTPS endpoint, klucz DPAPI, UI zgody i testy mock HTTP — wdrożone; (f) prawdziwy lookup z autoryzowanym kluczem, walidacja podpisu oraz opcjonalny, ograniczony monitoring Downloads — pozostają.
7. **Pliki:** engine file case, nowy core file analyzer/provider, UI, testy.
8. **Prywatność:** hash jest pseudonimizującym identyfikatorem; sieć nie jest używana bez osobnego kliknięcia; request zawiera hash i Auth-Key, bez nazwy/ścieżki/pliku. Klucz jest chroniony DPAPI CurrentUser i można go usunąć w UI.
9. **Testy:** .NET obejmuje lokalne dopasowanie oraz mock API: wynik znany, `no_results`, odrzucenie błędnego hasha i niezgodnego hashy w odpowiedzi. Test sprawdza stały host i wyłącznie form fields `query`/`hash`. Engine IPC sprawdza lokalny feed/scan, niepodpisany fixture i odrzuca sparse plik 256 MiB + 1 bajt przed hashowaniem; test przechodzi lokalnie i w Windows CI run `39431450078`. Dokładny limit 256 MiB i fixture z podpisem kryptograficznie ważnym/nieważnym nadal nie są testowane. Pełny .NET suite 176/176 PASS.
10. **Akceptacja:** brak listy lub brak dopasowania nigdy nie daje „bezpieczny”; UI opisuje źródło i ryzyko komercyjnych warunków; lookup jest jawny i hash-only; import lokalny jest atomowy i ograniczony.
11. **Ryzyka:** podpis legalny nie dowodzi bezpieczeństwa; nieznany plik nie dowodzi malware; feed ma licencję/false positive.
12. **Status:** `IN_PROGRESS` — ręczne SHA-256/Authenticode, lokalna lista hashy i opcjonalny hash-only lookup MalwareBazaar są wdrożone; 176 testów .NET, w tym mock API, oraz test Engine IPC limitu >256 MiB przechodzą. Windows CI dla limitu przeszło w runie `39431450078`. Test prawdziwego API czeka na osobisty klucz i potwierdzenie uprawnień/licencji do użycia; fixture zaufania Authenticode i monitoring pobrań pozostają.
