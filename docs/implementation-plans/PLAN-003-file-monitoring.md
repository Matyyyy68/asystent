# PLAN-003 — pliki i reputacja

1. **Cel:** na jawne żądanie oceniać wybrany plik przez hash, podpis i audytowane źródło reputacji.
2. **Stan obecny:** `Sentinel.Engine` na jawne żądanie otwiera wybrany plik do 256 MiB tylko do odczytu, liczy SHA-256, zwraca status Authenticode i sprawdza dokładne dopasowanie do lokalnej listy hashy zaimportowanej przez użytkownika. Opcjonalny lookup MalwareBazaar wysyła wyłącznie SHA-256 po osobnym kliknięciu; osobisty Auth-Key jest chroniony DPAPI. Dodatkowy, domyślnie wyłączony watcher katalogu `Downloads` bada nowe pliki bezpośrednio w tym katalogu względem lokalnego feedu; nie czyta podkatalogów, ignoruje reparse points, nie wykonuje lookupów sieciowych i zapisuje lokalne zdarzenie tylko przy dopasowaniu. Pauza zatrzymuje watcher. Brak dopasowania w którymkolwiek źródle nie jest werdyktem bezpieczeństwa.
3. **Braki:** niezależne źródło i świeżość lokalnego feedu, test z autoryzowanym kluczem przeciw prawdziwemu API, test na rzeczywiście przekierowanym Downloads. Trwałe wznowienie obserwacji nowych i zmienionych plików po restarcie silnika wdrożono w v0.15.23. W v0.15.19 watcher odtwarza w aktywnej sesji overflow kolejki/bufora; v0.15.20 ogranicza stan do 100 000 ścieżek i zatrzymuje monitoring po osiągnięciu limitu. Początkowe pliki nie są hashowane.
4. **Decyzje:** ręczny skan i jawne lookup; brak automatycznego odczytu prywatnych katalogów; brak uploadu/próbkowania plików. MalwareBazaar community API wymaga Auth-Key i jest domyślnie nieaktywne; przed użyciem należy zapoznać się z [warunkami dostawcy](https://bazaar.abuse.ch/api/), ponieważ zastosowanie komercyjne może wymagać płatnego API. Lokalny feed pozostaje dostępny offline.
5. **Zależności:** podpis Authenticode/WinVerifyTrust, osobisty Auth-Key i zgodność z warunkami źródła, model zdarzeń.
6. **Etapy:** (a) ograniczenie rozmiaru, uchwyt tylko do odczytu i TOCTOU — wdrożone; (b) sprawdzenie Authenticode przez izolowany Windows PowerShell bez ładowania profili — wdrożone; (c) lokalny provider dokładnych SHA-256 z limitem 20 MiB/250 000 wpisów i atomową walidacją — wdrożony; (d) ręczny wybór pliku do skanu i listy — wdrożone; (e) ręczny hash-only lookup MalwareBazaar, stały HTTPS endpoint, klucz DPAPI, UI zgody i testy mock HTTP — wdrożone; (f) ograniczony watcher Downloads z opt-in, lokalnym dopasowaniem, Known Folder resolverem, reconciliacją overflow, bounded SQLite v9 baseline z restart recovery i fixture trusted/tampered Authenticode — wdrożone; (g) prawdziwy lookup z autoryzowanym kluczem i test rzeczywiście przekierowanego Known Folder — pozostają.
7. **Pliki:** engine file case, nowy core file analyzer/provider, UI, testy.
8. **Prywatność:** hash jest pseudonimizującym identyfikatorem; sieć nie jest używana bez osobnego kliknięcia; request zawiera hash i Auth-Key, bez nazwy/ścieżki/pliku. Przy opt-in monitorze Downloads pełne ścieżki, rozmiary i czasy modyfikacji są lokalnie zapisane w nieszyfrowanej bazie, aby wznowić obserwację po restarcie; nie są wysyłane. Klucz jest chroniony DPAPI CurrentUser i można go usunąć w UI.
9. **Testy:** .NET obejmuje lokalne dopasowanie oraz mock API: wynik znany, `no_results`, odrzucenie błędnego hasha i niezgodnego hashy w odpowiedzi. Test sprawdza stały host i wyłącznie form fields `query`/`hash`. Engine IPC sprawdza prawdziwy podpis Authenticode `Valid` na systemowym PowerShell, zmodyfikowaną kopię o statusie innym niż `Valid`, niepodpisany fixture, lokalny feed/scan, odrzuca sparse plik 256 MiB + 1 bajt przed hashowaniem, a na izolowanym katalogu Downloads potwierdza zdarzenie lokalnego dopasowania i brak zdarzeń po wyłączeniu lub pauzie. Dodatkowe testy sprawdzają odzyskiwanie overflow, fail-closed limit baseline'u, restart z wykryciem nowego pliku, reset przy pauzie/wyłączeniu i usuwanie skasowanych ścieżek. Test migracji v8→v9 zachowuje historię. .NET 183/183, Engine IPC PASS; Windows CI/release v0.15.23 w toku.
10. **Akceptacja:** brak listy lub brak dopasowania nigdy nie daje „bezpieczny”; UI opisuje źródło i ryzyko komercyjnych warunków; lookup jest jawny i hash-only; import lokalny jest atomowy i ograniczony.
11. **Ryzyka:** podpis legalny nie dowodzi bezpieczeństwa; nieznany plik nie dowodzi malware; feed ma licencję/false positive.
12. **Status:** `IN_PROGRESS` — ręczne SHA-256/Authenticode, lokalna lista hashy, opcjonalny hash-only lookup MalwareBazaar i watcher Downloads po opt-in są wdrożone. Wydanie v0.15.23 przeszło Windows CI `39451059431` i installer self-test/release `39451070868`; Pages `39450039001` PASS. SQLite v9 przechowuje lokalny baseline i atomowo zapisuje event oraz fingerprint; po restarcie wykrywa nowe/zmienione pliki, a pauza/wyłączenie czyści baseline. Overflow jest odtwarzany w aktywnej sesji, limit wynosi 100 000 ścieżek. Test prawdziwego API czeka na autoryzowany klucz i potwierdzenie warunków/licencji; rzeczywiście przekierowany Known Folder wymaga testu.
