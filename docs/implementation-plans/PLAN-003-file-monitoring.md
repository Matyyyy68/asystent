# PLAN-003 — pliki i reputacja

1. **Cel:** na jawne żądanie oceniać wybrany plik przez hash, podpis i audytowane źródło reputacji.
2. **Stan obecny:** `Sentinel.Engine` na jawne żądanie otwiera wybrany plik do 256 MiB tylko do odczytu, liczy SHA-256, zwraca status Authenticode i sprawdza dokładne dopasowanie do lokalnej listy hashy zaimportowanej przez użytkownika. Opcjonalny lookup MalwareBazaar wysyła wyłącznie SHA-256 po osobnym kliknięciu; osobisty Auth-Key jest chroniony DPAPI. Dodatkowy, domyślnie wyłączony watcher katalogu `Downloads` bada nowe pliki bezpośrednio w tym katalogu względem lokalnego feedu; nie czyta podkatalogów, ignoruje reparse points, nie wykonuje lookupów sieciowych i zapisuje lokalne zdarzenie tylko przy dopasowaniu. Pauza zatrzymuje watcher. Brak dopasowania w którymkolwiek źródle nie jest werdyktem bezpieczeństwa.
3. **Braki:** niezależne źródło i świeżość lokalnego feedu, test z autoryzowanym kluczem przeciw prawdziwemu API, wykrywanie zmian w czasie, gdy silnik nie działa, test na rzeczywiście przekierowanym Downloads i trwałe wznowienie po restarcie procesu. W v0.15.19 watcher odtwarza w aktywnej sesji przepełnienie kolejki/bufora przez ograniczone ponowne porównanie stanu katalogu; baseline ma limit 100 000 plików i nie hashuje stanu początkowego.
4. **Decyzje:** ręczny skan i jawne lookup; brak automatycznego odczytu prywatnych katalogów; brak uploadu/próbkowania plików. MalwareBazaar community API wymaga Auth-Key i jest domyślnie nieaktywne; przed użyciem należy zapoznać się z [warunkami dostawcy](https://bazaar.abuse.ch/api/), ponieważ zastosowanie komercyjne może wymagać płatnego API. Lokalny feed pozostaje dostępny offline.
5. **Zależności:** podpis Authenticode/WinVerifyTrust, osobisty Auth-Key i zgodność z warunkami źródła, model zdarzeń.
6. **Etapy:** (a) ograniczenie rozmiaru, uchwyt tylko do odczytu i TOCTOU — wdrożone; (b) sprawdzenie Authenticode przez izolowany Windows PowerShell bez ładowania profili — wdrożone; (c) lokalny provider dokładnych SHA-256 z limitem 20 MiB/250 000 wpisów i atomową walidacją — wdrożony; (d) ręczny wybór pliku do skanu i listy — wdrożone; (e) ręczny hash-only lookup MalwareBazaar, stały HTTPS endpoint, klucz DPAPI, UI zgody i testy mock HTTP — wdrożone; (f) ograniczony watcher Downloads z opt-in, lokalnym dopasowaniem, Known Folder resolverem, reconciliacją overflow w aktywnej sesji i fixture trusted/tampered Authenticode — wdrożone; (g) prawdziwy lookup z autoryzowanym kluczem, test rzeczywiście przekierowanego Known Folder i wznowienie zmian po restarcie silnika — pozostają.
7. **Pliki:** engine file case, nowy core file analyzer/provider, UI, testy.
8. **Prywatność:** hash jest pseudonimizującym identyfikatorem; sieć nie jest używana bez osobnego kliknięcia; request zawiera hash i Auth-Key, bez nazwy/ścieżki/pliku. Klucz jest chroniony DPAPI CurrentUser i można go usunąć w UI.
9. **Testy:** .NET obejmuje lokalne dopasowanie oraz mock API: wynik znany, `no_results`, odrzucenie błędnego hasha i niezgodnego hashy w odpowiedzi. Test sprawdza stały host i wyłącznie form fields `query`/`hash`. Engine IPC sprawdza prawdziwy podpis Authenticode `Valid` na systemowym PowerShell, zmodyfikowaną kopię o statusie innym niż `Valid`, niepodpisany fixture, lokalny feed/scan, odrzuca sparse plik 256 MiB + 1 bajt przed hashowaniem, a na izolowanym katalogu Downloads potwierdza zdarzenie lokalnego dopasowania i brak zdarzeń po wyłączeniu lub pauzie. Wszystkie te IPC testy PASS lokalnie i w Windows CI run `39435405101`; pełny .NET suite 176/176 PASS. Resolver Known Folder i licznik przepełnienia przeszły Windows validation `39436563958` oraz installer release/self-test `39437009572` dla v0.15.18.
10. **Akceptacja:** brak listy lub brak dopasowania nigdy nie daje „bezpieczny”; UI opisuje źródło i ryzyko komercyjnych warunków; lookup jest jawny i hash-only; import lokalny jest atomowy i ograniczony.
11. **Ryzyka:** podpis legalny nie dowodzi bezpieczeństwa; nieznany plik nie dowodzi malware; feed ma licencję/false positive.
12. **Status:** `IN_PROGRESS` — ręczne SHA-256/Authenticode, lokalna lista hashy, opcjonalny hash-only lookup MalwareBazaar i watcher Downloads po opt-in są wdrożone. Testy .NET: 177/177 PASS; nowy test odtwarza pięć plików po overflow sztucznie ograniczonej kolejki, nie skanując pliku sprzed włączenia. Engine IPC, Windows validation/release/self-test v0.15.18 PASS w runach `39436563958`/`39437009572`. Lokalny build/self-test v0.15.19 PASS; Windows CI i release jeszcze pending. Test prawdziwego API czeka na autoryzowany klucz i potwierdzenie warunków/licencji; rzeczywiście przekierowana ścieżka i wznowienie zmian po restarcie silnika pozostają.
