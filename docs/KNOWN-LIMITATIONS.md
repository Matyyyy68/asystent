# Znane ograniczenia — 2026-10-20

- To wersja rozwojowa. Prerelease [v0.15.14](https://github.com/Matyyyy68/asystent/releases/tag/v0.15.14) zawiera poprawkę ekstrakcji, test baz SQLite i smoke aplikacji. Kandydat 0.15.15 dodaje trwały baseline monitoringu TCP/UDP i przechodzi lokalny pełny build/self-test; oczekuje na publikację. Pełny cykl GUI, aktualizacja, rollback, deinstalacja, autostart po logowaniu i działanie rozszerzenia nadal wymagają ręcznej walidacji na czystym Windows.
- Instalator nie używa MSI ani NSIS. Polityki organizacji mogą ograniczyć uruchamianie niepodpisanych aplikacji, zmianę ACL lub rejestrację hosta przeglądarki.
- DNS to próbkowany cache Windows, nie strumień zapytań. Kanał `Microsoft-Windows-DNS-Client/Operational` jest wyłączony na maszynie audytu i nie był włączany. DoH, VPN, wpisy cache usunięte między próbkami i połączenia po IP mogą zostać pominięte. Nie ma PID ani pełnego URL. TCP snapshot i opt-in polling pokazują wyłącznie metadane. UDP opt-in zapisuje pojawienie się lokalnego endpointu, lecz nie potwierdza transferu i nie pokazuje zdalnego celu; reputacja IP pozostaje niewdrożona.
- WFP, blokowanie ruchu i filtr jądra nie są wdrożone. Nie modyfikujemy ustawień DNS. Ostrzeżenie rozszerzenia może nastąpić już po rozpoczęciu ładowania strony.
- Lista CERT Polska zawiera domeny związane z phishingiem/oszustwami i jest ręcznie aktualizowana; po 48 h jest uznawana za wygasłą. Brak reputacji IP i pełnych URL malware. MalwareBazaar jest opcjonalny i wymaga osobistego Auth-Key; użycie komercyjne może wymagać płatnego API zgodnie z warunkami dostawcy. URLhaus nie jest podłączony.
- Ręczny skan pliku (do 256 MiB) liczy SHA-256, pokazuje status Authenticode i dopasowanie do lokalnej listy hashy importowanej przez użytkownika. Opcjonalne zapytanie MalwareBazaar wysyła tylko SHA-256 po osobnym kliknięciu, a Auth-Key przechowuje DPAPI CurrentUser. Nie wykonano realnego lookup bez klucza. Lokalna lista nie ma niezależnie uwierzytelnionego źródła; brak dopasowania nie oznacza bezpieczeństwa. Nie ma monitorowania pobieranych plików ani poczty/SMS/formularzy.
- Lokalna analiza deterministyczna działa bez sieci. Opcjonalny provider Ollama i wyszukiwanie lokalnej bazy FTS5 są podłączone do aktywnego klienta; Ollama wymaga jawnego włączenia, lokalnie działającego modelu i nie została zweryfikowana z rzeczywistym modelem na maszynie audytu. Baza wiedzy nie używa embeddingów, więc nie jest semantycznym RAG.
- Dane SQLite nie są szyfrowane. Host Native Messaging Chrome/Edge jest lokalny, ale instalację rozszerzenia trzeba wykonać ręcznie. Diagnostyka „kontakt” nie oznacza stałego połączenia.
- Powiadomienia automatyczne dotyczą dopasowań DNS do feedu. Ręczna analiza tekstu, URL i pliku prezentuje wynik w UI. Diagnostyka silnika pokazuje CPU/RAM; nie ma bezpiecznego autoupdate aplikacji/modelu.
- Zachowany kod WPF jest w `legacy/` i nie należy do wspieranego buildu. Stare skrypty instalatora w `legacy/installer/` i `legacy/scripts/` są historyczne i nie budują aktualnego klienta.
- W repozytorium nie ma pliku LICENSE. Przed publiczną dystrybucją właściciel musi ustalić licencję kodu i warunki redystrybucji pakietu; witryna nie oferuje niezweryfikowanego pliku.
- Wcześniejszy udany `npm audit --omit=dev` dla desktop zgłaszał zero podatności runtime. Pełny audit wykazał osiem umiarkowanych ścieżek pośrednich w narzędziach deweloperskich przez `sprintf-js@1.1.3` w `electron-builder`; ponowny audit 2026-10-20 nie dotarł do registry.npmjs.org. [GitHub Advisory dla CVE-2026-97058](https://github.com/advisories/GHSA-hp3w-g68c-fv3c) nie podaje poprawionej wersji. Ponowić audit po przywróceniu dostępu do registry; nie wymuszać downgrade'u buildera bez testów kompatybilności.
