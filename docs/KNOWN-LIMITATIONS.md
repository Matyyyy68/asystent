# Znane ograniczenia — 2026-10-20

- To wersja rozwojowa. [Prerelease v0.15.28](https://github.com/Matyyyy68/asystent/releases/tag/v0.15.28) przeszła Windows CI, Pages, installer build/self-test i zawiera instalator 262536309 B (SHA-256 `5834d0d220d14ad93d39af75f2328cba10985921ca4f6b0acc22e134901bbf63`). SQLite v9 trwale zapisuje baseline procesów i metadane plików Downloads; opt-in watcher wznawia wykrywanie zmian po restarcie, odtwarza overflow i automatycznie ponawia start po błędzie bazy w kolejnym cyklu collect. Klient Electron ponawia start procesu silnika po awarii lub braku odpowiedzi przez 45 s; UI diagnostyczne pokazuje lifecycle i kod zakończenia bez treści stderr. Pełny cykl GUI, aktualizacja, rollback, deinstalacja, autostart po logowaniu i działanie rozszerzenia nadal wymagają ręcznej walidacji na czystym Windows.
- Instalator nie używa MSI ani NSIS. Polityki organizacji mogą ograniczyć uruchamianie niepodpisanych aplikacji, zmianę ACL lub rejestrację hosta przeglądarki.
- DNS to próbkowany cache Windows, nie strumień zapytań. Kanał `Microsoft-Windows-DNS-Client/Operational` jest wyłączony na maszynie audytu i nie był włączany. DoH, VPN, wpisy cache usunięte między próbkami i połączenia po IP mogą zostać pominięte. Nie ma PID ani pełnego URL. TCP snapshot i opt-in polling pokazują wyłącznie metadane. UDP opt-in zapisuje pojawienie się lokalnego endpointu, lecz nie potwierdza transferu i nie pokazuje zdalnego celu; reputacja IP pozostaje niewdrożona.
- WFP, blokowanie ruchu i filtr jądra nie są wdrożone. Nie modyfikujemy ustawień DNS. Ostrzeżenie rozszerzenia może nastąpić już po rozpoczęciu ładowania strony.
- Lista CERT Polska zawiera domeny związane z phishingiem/oszustwami i jest ręcznie aktualizowana; po 48 h jest uznawana za wygasłą. Brak reputacji IP i pełnych URL malware. MalwareBazaar jest opcjonalny i wymaga osobistego Auth-Key; użycie komercyjne może wymagać płatnego API zgodnie z warunkami dostawcy. URLhaus nie jest podłączony.
- Ręczny skan pliku (do 256 MiB) liczy SHA-256, pokazuje status Authenticode i dopasowanie do lokalnej listy hashy importowanej przez użytkownika. Opcjonalne zapytanie MalwareBazaar wysyła tylko SHA-256 po osobnym kliknięciu, a Auth-Key przechowuje DPAPI CurrentUser. Nie wykonano realnego lookup bez klucza. Lokalna lista nie ma niezależnie uwierzytelnionego źródła; brak dopasowania nie oznacza bezpieczeństwa. W v0.15.25 monitoring plików Downloads jest domyślnie wyłączony; po opt-in porównuje je wyłącznie lokalnie z listą, a SQLite v9 zapamiętuje baseline na restart. Pauza/wyłączenie czyści baseline, więc pliki z tego okresu stają się stanem początkowym po ponownym włączeniu. Nie skanuje podkatalogów ani plików pobranych przed włączeniem. Overflow jest odtwarzany przez ponowne porównanie katalogu. Limit stanu zatrzymuje monitoring po osiągnięciu 100 000 ścieżek. Nie monitoruje poczty/SMS/formularzy.
- Lokalna analiza deterministyczna działa bez sieci. Opcjonalny provider Ollama i wyszukiwanie lokalnej bazy FTS5 są podłączone do aktywnego klienta; pasujące fragmenty trafiają do promptu jako niezaufane źródła. Ollama wymaga jawnego włączenia, lokalnie działającego modelu i nie została zweryfikowana z rzeczywistym modelem na maszynie audytu. Baza wiedzy nie używa embeddingów, więc nie jest semantycznym RAG.
- Dane SQLite nie są szyfrowane. Host Native Messaging Chrome/Edge jest lokalny, ale instalację rozszerzenia trzeba wykonać ręcznie. Diagnostyka „kontakt” nie oznacza stałego połączenia.
- Powiadomienia automatyczne dotyczą dopasowań DNS do feedu. Ręczna analiza tekstu, URL i pliku prezentuje wynik w UI. Diagnostyka silnika pokazuje lifecycle, CPU/RAM; nie ma bezpiecznego autoupdate aplikacji/modelu.
- Zachowany kod WPF jest w `legacy/` i nie należy do wspieranego buildu. Stare skrypty instalatora w `legacy/installer/` i `legacy/scripts/` są historyczne i nie budują aktualnego klienta.
- W repozytorium nie ma pliku LICENSE. Przed publiczną dystrybucją właściciel musi ustalić licencję kodu i warunki redystrybucji pakietu; witryna nie oferuje niezweryfikowanego pliku.
- `npm audit --omit=dev` 2026-10-20 zwrócił zero podatności runtime. Pełny audit wykonany wcześniej potwierdził osiem umiarkowanych ścieżek build-time przez `sprintf-js@1.1.3` w `electron-builder`. [GitHub Advisory dla CVE-2026-97058](https://github.com/advisories/GHSA-hp3w-g68c-fv3c) opisuje DoS przez nieograniczoną precyzję i nie podaje jeszcze poprawionej wersji; obecna sesja nie mogła połączyć się z rejestrem npm, by powtórzyć audit. Proponowany downgrade buildera z `^26.15.3` do 26.5.0 zamiast tego dodał 8 high i 1 critical przez `tar`/electron-builder. Przywrócono 26.15.3; ponowić audit, gdy poprawka upstream będzie dostępna.
