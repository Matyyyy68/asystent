# Znane ograniczenia — 2026-10-22

Sentinel AI pozostaje prerelease i nie zastępuje Microsoft Defender ani innego produktu ochronnego. Brak ostrzeżenia nie potwierdza bezpieczeństwa; reguły i pomiary testowe nie dowodzą skuteczności na rzeczywistych atakach.

## Wydanie i instalacja

- Publicznym wydaniem pozostaje [v0.15.38](https://github.com/Matyyyy68/asystent/releases/tag/v0.15.38). Bieżący `main` zawiera późniejsze poprawki, w tym automatyczną rotację poświadczeń Enterprise po 90 dniach. Zmiany te nie trafiły jeszcze do opublikowanego instalatora; lokalny build bieżącego kodu nie jest publicznym wydaniem.
- Pełny build i self-test instalatora przechodzą. `--integration-test` dla artefaktu z 2026-10-23 przeszedł poza sandboxem: instalacja, wpis deinstalacji i Native Messaging, a następnie deinstalacja i kontrola sprzątania. Pełnego cyklu GUI, instalacji z włączonymi skrótami i autostartem oraz update/uninstall w normalnym profilu nie zweryfikowano na czystym Windows. Próba z 2026-10-22 potwierdziła otwarcie kreatora i ustawienie izolowanej ścieżki `%LOCALAPPDATA%\\Programs\\Sentinel-AI-Audit-2026-10-22`. Zrzut obrazu przekroczył limit czasu, a UI Automation nie udostępniła geometrii przycisków; instalator zamknięto przed kopiowaniem plików, rejestracją lub zmianami autostartu i skrótów.
- Instalator nie jest podpisany Authenticode, nie ma podpisanego manifestu aktualizacji ani automatycznego updatera. Nie należy traktować lokalnego SHA-256 jako podpisu wydawcy.
- Rozszerzenie Chrome/Edge wymaga ręcznego załadowania. Testy automatyczne na fixture `.test` przeszły 4/4. Próba uruchomienia Chrome w osobnym profilu testowym 2026-10-23 zakończyła się natychmiastową awarią procesu, zanim dało się sprawdzić interfejs; nie dodano rozszerzenia do zwykłego profilu. Ostrzeżenie może pojawić się po rozpoczęciu ładowania strony i nie blokuje nawigacji.

## Analiza i źródła zdarzeń

- Ręczna analiza URL/tekstu używa lokalnych reguł i ograniczonych heurystyk (`2026.10.6`). Testy obejmują 32 jawnie syntetyczne przypadki (15 TP, 17 TN) oraz regresje brandowych domen i mieszanych IDN. Eksploracyjna ewaluacja całego UCI PhiUSIIL (URL-only, bez holdoutu i deduplikacji) dała recall 4,3222%, precision 99,8855% i FPR 0,0037% przy progu Moderate. Większość phishingowych adresów nadal nie wywołała alarmu; ten zbiór był wcześniej eksplorowany, więc wynik nie jest niezależną ani produkcyjną miarą. Confidence pozostaje puste bez kalibracji. Metoda i reprodukcja: [DETECTION-EVALUATION.md](DETECTION-EVALUATION.md).
- Ekran ręcznej analizy ostrzega, że brak alarmu nie potwierdza bezpieczeństwa, a Sentinel nie blokuje stron i nie zastępuje Defendera. Przy regułach `2026.10.6` pokazuje też niezależny wynik PhishVN v3.1.0: 0/487 phishingowych URL-i wykrytych w testowym podzbiorze gold/silver. To wynik konkretnego zbioru, nie przewidywanie skuteczności dla wszystkich adresów.
- Lista CERT Polska wymaga ręcznego pobrania, wygasa po 48 godzinach i dotyczy domen. Reputacja IP jest dostępna tylko dla jawnie zaimportowanej przez użytkownika listy IP/CIDR i nowych połączeń TCP przy włączonym monitoringu; Sentinel nie weryfikuje źródła ani licencji tej listy. Nie ma automatycznego feedu IP, pokrycia UDP ani reputacji pełnych URL-i malware; URLhaus nie jest podłączony.
- Cache DNS Windows jest próbkowany, a nie odczytywany jako strumień zapytań. Read-only parser/reader zdarzenia 3008 z kanału `Microsoft-Windows-DNS-Client/Operational` wdrożono dla kanału, który jest już włączony; nie zapisuje on odpowiedzi DNS. Na maszynie audytu kanał jest wyłączony, więc zweryfikowano tylko fallback, a nie live odczyt zdarzeń. Sentinel kanału nie włącza. DoH, VPN, zapytania po IP oraz wpisy usunięte między próbkami mogą zostać pominięte.
- Procesy są próbkowane lokalnie co około sekundę; opt-in monitoring TCP/UDP również odpyta tabele Windows co około sekundę. Krótkie procesy lub połączenia mogą zakończyć się między próbkami. Tabele są ograniczone do 10 000 procesów, 800 wpisów TCP i 200 UDP; niepełne próbki wstrzymują niepewne alerty. UDP pokazuje lokalny endpoint, nie potwierdza datagramu ani nie ujawnia zdalnego celu. Nie ma gwarantowanego event stream: próby WMI i sesji ETW wymagały dostępu systemowego, którego konto audytu nie miało.
- Nie ma WFP, sterownika jądra, filtrowania ani automatycznego blokowania ruchu. Sentinel nie przechwytuje payloadu HTTPS ani nie instaluje certyfikatu do inspekcji TLS.
- Monitoring Downloads jest opt-in i obejmuje nowe/zmienione pliki w podfolderach do 256 MiB na plik; nie skanuje plików istniejących przed włączeniem. Pomija reparse points, a pełne uzgodnienie baseline'u wykonuje co 5 minut (limit 100 000 plików). Porównanie SHA-256 działa lokalnie z listą importowaną przez użytkownika. Nazwy/ścieżki, rozmiary i czasy plików są zapisywane lokalnie bez szyfrowania. Brak dopasowania nie oznacza bezpieczeństwa.
- Ręczny skan pliku liczy SHA-256 i sprawdza status Authenticode. Opcjonalny MalwareBazaar lookup wysyła wyłącznie hash po osobnym kliknięciu i wymaga klucza API; nie został sprawdzony z rzeczywistym kluczem. Warunki komercyjnego użycia zależą od dostawcy.
- Ollama wymaga osobnej instalacji, lokalnego modelu i jawnego włączenia; nie zostało zweryfikowane na rzeczywistym modelu na maszynie audytu. Baza wiedzy używa FTS5, nie embeddingów ani wyszukiwania semantycznego; PDF bez warstwy tekstowej wymagałby OCR, którego nie ma.

## Enterprise, dane i prywatność

- Monitoring trwałości Windows jest opt-in i obejmuje HKCU/HKLM Run/RunOnce (widoki 32/64-bit), bezpośrednie pliki Startup użytkownika/wspólnego Startup, Scheduled Tasks przez `schtasks /query /xml` oraz usługi i sterowniki z `HKLM\SYSTEM\CurrentControlSet\Services`. Dla usług/sterowników hashuje wybrane wartości konfiguracji; nazwy, polecenia i ścieżki nie są zapisywane. Trwały, zredagowany baseline wykrywa różnice przy kolejnej próbce/restarcie, ale nie wykrywa zmian dodanych i cofniętych podczas zamknięcia. Odczyt zadań może wymagać dodatkowych uprawnień; przy odmowie monitor zachowuje poprzedni baseline i raportuje ograniczenie. Live test odczytu rejestru nie przeszedł w ograniczonym środowisku (`SecurityException`); nie zmieniano uprawnień. Snapshot jest ograniczony do 1024 elementów łącznie, a odczyt zadań do 8 MiB; większy lub nieprawidłowy snapshot wstrzymuje próbkę. Cichy baseline nie alarmuje o stanie zastanym przy pierwszym dostępie. Reguła lokalizacji jest heurystyczna.

- Serwer Enterprise jest osobnym projektem. Wdrożenie poza loopback wymaga HTTPS z certyfikatem zaufanym przez Windows; repozytorium nie dostarcza publicznego serwera ani zaufanego certyfikatu. Instalator serwera nie konfiguruje TLS ani zapory.
- Klient przesyła metadane zdarzeń wyłącznie po jawnej zgodzie. Nie obejmują one treści, pełnych URL-i, zawartości plików, nazw aplikacji ani lokalnych wyjaśnień. Podczas rejestracji serwer otrzymuje kod zaproszenia, nazwę komputera i wersję klienta. Szczegóły opisuje [konfiguracja klienta Enterprise](ENTERPRISE-CLIENT-SETUP.md).
- Polityka klienta Enterprise obsługuje obecnie tryb lokalny i ograniczony interwał. Serwerowa analiza treści oraz rozszerzone statusy zgodności pozostają poza zwykłym przepływem agenta. Urządzenie oczekujące na akceptację wymaga działania administratora.
- Token Enterprise jest chroniony Windows DPAPI; nowszy kod `main` odnawia go automatycznie po 90 dniach przy aktywnej zgodzie i synchronizacji. Ta funkcja nie znajduje się jeszcze w publicznym instalatorze v0.15.38.
- Bazy SQLite nie są szyfrowane. Historia nie zapisuje surowej treści ani pełnych URL-i, ale lokalne metadane, ustawienia i ścieżki monitorowanych plików mogą być dostępne dla konta użytkownika.
- W repozytorium nie ma pliku LICENSE. Właściciel musi wskazać licencję źródeł i warunki redystrybucji; nie zostały ustalone w jego imieniu.
- Inwentaryzacja obejmuje 23 pary NuGet oraz wszystkie 290 par npm z lockfile; 240 jest zainstalowanych lokalnie, a 50 lockfile-only. Każdy wpis npm ma deklarację w lockfile, ale warunki redystrybucji 50 pakietów niedostępnych lokalnie i deklaracje nietypowe wymagają ręcznego przeglądu. Pełna zgodność redystrybucji nie została ustalona. Szczegóły i CSV: [inwentaryzacja licencji zależności](DEPENDENCY-LICENSE-AUDIT.md).

# Process image inspection

Process start monitoring is snapshot-based and may miss processes shorter than the polling interval. Image paths can be unavailable due to Windows access restrictions. Background SHA-256 and Authenticode inspection is limited to 256 MiB and a queue of 33 (including one in-flight item); excess work is marked `QueueFull` and pending work is retried after engine restart. Local hash comparison only reflects a user-imported feed. An absent match is not a clean verdict, and an unsigned file is not by itself malware. Paths and hashes are stored in local history and are omitted from JSON/CSV exports and Enterprise payloads. WMI/ETW event-stream collection is not implemented because the tested account lacked access.
